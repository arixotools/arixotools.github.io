About the Color Converter

Designers and developers move between color formats all the time. HEX codes are common in CSS and design tools, RGB is used in code and image editors, and HSL describes color the way people think about it, as a hue, a saturation and a lightness. This converter reads any of the three and shows the others with a live color swatch.

How to use the Color Converter

  1. Paste or type a color, such as #1e90ff, rgb(30, 144, 255) or hsl(210, 100%, 56%).
  2. The HEX, RGB and HSL values and a color preview appear instantly.
  3. Copy the format your project needs.

Where it is useful

  • Matching colors between a design file and CSS.
  • Building color palettes and shades with HSL.
  • Converting brand colors for web, print references and apps.
  • Learning how color codes relate to each other.

How the formats relate

FormatExampleMeaning
HEX#1E90FFRed, green and blue as two hex digits each
RGBrgb(30, 144, 255)Red, green and blue from 0 to 255
HSLhsl(210, 100%, 56%)Hue in degrees, saturation and lightness in percent

A short HEX such as #f80 expands to #ff8800. In HSL, keeping the hue and changing the lightness gives lighter or darker shades of the same color.

Tips for choosing colors

For readable text, use enough contrast between the text color and its background. Web accessibility guidelines recommend a contrast ratio of at least 4.5 to 1 for normal text.

Tips and common mistakes

  • A # in front of a HEX code is optional.
  • Transparency (alpha) values are accepted but not shown in the result.
  • HSL is the easiest format for making consistent lighter and darker shades.
  • Colors may look slightly different on different screens.

Frequently asked questions

How do I convert HEX to RGB?

Split the HEX into three pairs and convert each from base 16 to decimal. This tool does it instantly.

What is HSL?

A color format using hue, saturation and lightness.

Can I enter a color name like red?

Not yet. Use HEX, RGB or HSL values.

What does #fff mean?

It is short for #ffffff, which is white.

Does it support alpha transparency?

Alpha values are accepted but ignored in the converted result.
