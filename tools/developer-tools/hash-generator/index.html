What is a hash generator?

A hash function turns any input into a fixed-length string of letters and numbers. The same input always gives the same hash, and even a one-character change produces a completely different result. This makes hashes useful for checking that data has not changed, comparing values without storing them, and creating identifiers. This tool computes five common hashes from your text at the same time.

How to use it

  1. Type or paste your text into the box. Hashes appear as you type.
  2. Tick UPPERCASE if you need capital letters.
  3. Use the Copy button next to the hash you want.
  4. Click Clear to start again.

MD5 and SHA-1 have known collision weaknesses, so avoid them where security matters. They are still fine for non-security tasks such as spotting accidental changes.

If your hash differs from another tool, check for a hidden trailing space or new line. Either one changes the result.

Common uses of hashes

  • Verifying downloads: publishers list a checksum so you can confirm your copy is unchanged.
  • Finding duplicates: identical content produces identical hashes, which helps spot duplicate files or records.
  • Cache keys and ETags: a short hash of the content makes a convenient identifier.
  • Debugging: comparing hashes is a quick way to see whether two strings are really the same, including hidden characters.

Important: hashing is not encryption

A hash cannot be turned back into the original text, but short or common inputs can be guessed and checked. For storing passwords, use a dedicated password-hashing method such as bcrypt, scrypt or Argon2 rather than a plain MD5 or SHA hash. This tool hashes text only, not files.

Frequently asked questions

Can I decode a hash back to text?

No. Hash functions are one-way. Anyone can only guess the input and compare hashes.

Is MD5 safe to use?

Not for security. MD5 is broken for collision resistance. It is fine for simple checksums where no attacker is involved.

Why is my hash different from another tool?

Hidden spaces, line breaks or a different text encoding change the result. This tool uses UTF-8 and hashes exactly what you type.

Is my text sent to a server?

No. The hashes are generated in your browser using the Web Crypto API, plus a local MD5 routine.

Which hash is best for file integrity?

SHA-256 is a common choice. This page hashes text only, so use a dedicated tool for files.

Why do the SHA hashes say “Not available”?

The browser's Web Crypto feature needs a secure HTTPS page. Open the site over HTTPS and try again.
