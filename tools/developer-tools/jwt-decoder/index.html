About the JWT Decoder

A JSON Web Token (JWT) is a compact string used to carry login and access information between systems. It has three parts separated by dots: a header, a payload with claims such as the user ID and expiry, and a signature. The first two parts are just Base64URL-encoded JSON, so they can be read by anyone. This decoder turns them into readable JSON and shows the issue and expiry times as normal dates.

How to use the JWT Decoder

  1. Paste the token. A leading 'Bearer ' is removed automatically.
  2. Click Decode token.
  3. Read the header, payload, algorithm, and issue and expiry times.
  4. Use Copy result if you want to keep the decoded JSON.

Where it is useful

  • Debugging login and API problems.
  • Checking whether a token has expired.
  • Seeing which claims and roles a token carries.
  • Learning how JWTs are built.

What the parts mean

PartContains
HeaderThe signing algorithm (alg) and token type (typ)
PayloadClaims such as sub (subject), iat (issued at), exp (expiry) and custom data
SignatureA cryptographic signature that proves the token was not changed

Important: decoding is not verifying

This tool only reads the token. It does not check the signature, so it cannot tell you whether a token is genuine or has been tampered with. Verification needs the secret or public key and must be done on your server. Also remember that anything in a JWT payload is readable by anyone, so never put secrets in it.

Tokens can grant access to accounts. This page decodes in your browser and sends nothing anywhere, but you should still avoid pasting live production tokens into tools you do not trust.

Tips and common mistakes

  • Expiry (exp) and issued-at (iat) are in seconds since 1970 and are shown here as UTC dates.
  • A token without an exp claim never expires on its own.
  • Do not store sensitive data in the payload.
  • To check if two parts match your expectations, use the Base64 and JSON tools.

Frequently asked questions

What is a JWT?

A signed token that carries claims, used for authentication and authorization in web apps and APIs.

Can anyone read a JWT?

Yes. The header and payload are only encoded, not encrypted.

Does this tool verify the signature?

No. It only decodes. Verify signatures on your server with the proper key.

What do iat and exp mean?

iat is when the token was issued and exp is when it expires, both in Unix time.

Is my token sent anywhere?

No. Decoding happens in your browser.
