About the JSON Validator

The JSON Validator checks whether your text is valid JSON and shows an error message when it is not. It is useful when debugging API responses, configuration files and data exports. You can also format valid JSON in one click.

How to use

  1. Paste your JSON into the input box.
  2. Click Validate JSON.
  3. Fix any error shown, or click Format JSON to tidy valid data.

Where it is useful

  • Checking JSON before sending it to an API.
  • Finding errors in configuration files.
  • Testing data copied from other sources.
  • Learning what valid JSON looks like.

Common JSON errors

ProblemExampleFix

Unquoted key{a:1}Quote the key
Missing bracket[1,2Add the closing ]

Tips and common mistakes

  • Validation checks syntax only, not whether the values make sense.
  • Numbers must not have leading zeros.
  • Use Format afterwards to make valid JSON easy to read.
  • True, false and null must be lowercase.

Frequently asked questions

What makes JSON invalid?

Typical problems are trailing commas, unquoted keys, single quotes, comments and mismatched brackets or braces.

Does it check my data against a schema?

No. It checks syntax only, not whether the values match a particular schema.

Is my data uploaded?

No. Validation runs in your browser.

What does an error message mean?

It points to where the parser stopped understanding the text.

Does it check JSON schema?

No, only syntax.
