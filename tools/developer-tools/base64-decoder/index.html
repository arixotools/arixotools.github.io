About the Base64 Decoder

The Base64 Decoder converts Base64-encoded strings back into readable text. Developers use it to inspect API responses, tokens, configuration values and email content. Decoding happens in your browser, so your text is not sent to a server.

How to use

  1. Paste the Base64 string into the box.
  2. Click Decode.
  3. Copy the decoded text with the Copy button.

Frequently asked questions

What is Base64?

Base64 is a way of representing data using 64 printable characters. It is commonly used to carry binary or special characters safely inside text.

Is Base64 encryption?

No. Base64 is an encoding, not encryption. Anyone can decode it, so never use it to protect secrets.

Why do I get an error?

The input may not be valid Base64. Check for missing characters, extra spaces or an incorrect length.
