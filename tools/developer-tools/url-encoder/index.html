About the URL Encoder

The URL Encoder converts text into a form that is safe to use inside a web address. Spaces, symbols and non-English characters are replaced with percent codes. Use it for query parameters, links and API requests.

How to use

  1. Type or paste your text or URL.
  2. Click Encode.
  3. Copy the encoded result.

Frequently asked questions

When should I encode a URL?

Encode any text you place into a query string or path, especially if it contains spaces, symbols or non-English characters.

Should I encode a whole URL?

Usually you encode only the parameter values. Encoding the entire URL also changes characters like : and /, which may break it.

Is my text sent to a server?

No. Encoding is done in your browser.
