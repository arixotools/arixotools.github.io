About the UUID Generator

A UUID (universally unique identifier), also called a GUID, is a 128-bit identifier that is practically unique without any central registry. Developers use them as database keys, file names, session IDs and tracking IDs. This generator creates random version 4 UUIDs using your browser's secure random number source, one at a time or up to 100 at once.

How to use the UUID Generator

  1. Enter how many UUIDs you need.
  2. Choose the format and tick Uppercase if you want capital letters.
  3. Click Generate UUIDs.
  4. Click Copy result to copy the list.

Where it is useful

  • Creating primary keys and record IDs.
  • Naming uploads and temporary files so they never clash.
  • Generating test data for development.
  • Making unique tokens for tracking and sessions.

UUID format

xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx

The 4 shows this is version 4 (random), and y is one of 8, 9, a or b. A UUID has 32 hexadecimal digits in groups of 8-4-4-4-12. Version 4 has 122 random bits, so the chance of two matching is extremely small.

Good to know

UUIDs identify things but are not secrets and should not be used as passwords. For strong passwords use the Password Generator tool.

Tips and common mistakes

  • Store UUIDs in a native UUID type when your database has one, as it saves space.
  • Choose 'No hyphens' only if your system expects the compact form.
  • Do not rely on UUIDs for security tokens without extra safeguards.
  • If you need sortable IDs, newer UUID versions may be a better fit.

Frequently asked questions

What is a UUID?

A 128-bit identifier written as 32 hexadecimal digits, designed to be unique without coordination.

Is a UUID the same as a GUID?

Essentially yes. GUID is the name used in Microsoft systems.

Can two UUIDs be the same?

It is theoretically possible, but the chance with version 4 is vanishingly small.

Are these UUIDs safe to use in production?

They come from your browser's secure random generator, which is suitable for general identifiers.

Are my UUIDs stored?

No. They are generated in your browser and not saved or sent anywhere.
