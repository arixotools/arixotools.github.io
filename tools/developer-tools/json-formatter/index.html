About the JSON Formatter

The JSON Formatter makes messy JSON easy to read by adding indentation and line breaks, or shrinks it by removing whitespace. It also tells you when your JSON has a syntax error. Everything runs in your browser, so your data stays on your device.

How to use

  1. Paste your JSON into the input box.
  2. Click Format JSON to beautify it, or Minify JSON to compress it.
  3. Copy the result with the Copy button.

Frequently asked questions

What is the difference between format and minify?

Formatting adds indentation so people can read the data. Minifying removes spaces and line breaks to make it smaller for transfer.

Why does my JSON show an error?

Common causes are missing quotes around keys, trailing commas, single quotes instead of double quotes, or unmatched brackets.

Is my JSON sent to a server?

No. Formatting happens in your browser.
