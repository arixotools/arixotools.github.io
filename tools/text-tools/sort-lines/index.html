Sort Lines Alphabetically

Sort a list of lines alphabetically, by length, by number, or reverse it.

About the Sort Lines Alphabetically

Sorting a list by hand is slow and error-prone. Paste your lines and this tool sorts them A to Z or Z to A, by length, or by numeric value, and can also simply reverse the order. It is useful for tidying name lists, keywords, URLs, to-do items and numbers, and the result updates instantly as you change an option.

How to use the Sort Lines Alphabetically

  1. Paste your list, one item per line.
  2. Choose a sort order from the menu.
  3. Tick Ignore case if capitals should not affect the order, and Remove empty lines to tidy blanks.
  4. Click Copy result to take the sorted list.

Where it is useful

  • Alphabetising names, tags, keywords and bibliography entries.
  • Sorting numbers or prices from low to high.
  • Putting URLs or file names in order.
  • Reversing a list, such as a timeline, without retyping.

Sort options explained

OptionWhat it does
A to Z / Z to AAlphabetical order, forwards or backwards
Shortest / Longest firstOrders lines by number of characters
Numbers low/highReads each line as a number. Lines that are not numbers go to the end
ReverseFlips the current order without sorting

Remember to turn on Ignore case if you want 'apple' and 'Banana' sorted together regardless of capital letters.

Tips and common mistakes

  • For a unique sorted list, run Remove Duplicate Lines first or afterwards.
  • Numeric sorting understands commas in numbers such as 1,250.
  • Lines that start with spaces may sort first, so clean them with the Remove Spaces tool if needed.
  • Non-English letters are sorted using your browser's language rules.

Frequently asked questions

How do I sort a list alphabetically?

Paste the list, keep A to Z selected and copy the result.

Can it sort numbers correctly?

Yes. Choose 'Numbers, low to high' so 10 comes after 9, not after 1.

Is the sort case sensitive?

Not by default. Untick Ignore case to be case sensitive.

Can I reverse a list?

Yes, pick 'Reverse the current order'.

Does it work with Bangla or Hindi text?

It sorts using your browser's rules for the script, which is usually correct for common languages.
