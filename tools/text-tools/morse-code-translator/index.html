About the Morse Code Translator

Morse code represents letters and numbers as short and long signals, written as dots and dashes. It is still used by radio amateurs, in aviation and navigation, and for emergency signals. This translator converts plain text into Morse code and also decodes Morse back into text. It detects which way you want to go from what you type.

How to use the Morse Code Translator

  1. Type a message to turn it into Morse, or paste Morse made of dots and dashes to decode it.
  2. Separate Morse letters with a space and words with a slash.
  3. Read the result straight away.

Where it is useful

  • Learning Morse code for amateur radio or scouting.
  • Decoding puzzles, escape rooms and geocaching clues.
  • Creating messages for fun and school projects.
  • Checking the Morse for SOS and other common signals.

Writing Morse by hand

Use a space between the letters of a word and a forward slash between words. For example, "HI THERE" is .... .. / - .... . .-. ..

Tips and common mistakes

  • Characters that Morse does not cover show as a question mark.
  • Mixed input is treated as text, so keep Morse made only of dots, dashes, spaces and slashes.
  • Morse has no lowercase, so all text is read as capitals.
  • Real-time Morse also depends on timing, which is not shown here.

Frequently asked questions

What is SOS in Morse code?

It is ... --- ... three dots, three dashes, three dots.

How do I separate words in Morse?

With a slash or a longer gap. This tool uses a slash.

Can it decode Morse?

Yes. Paste dots and dashes and it translates to text.

Are numbers supported?

Yes, 0 to 9 and common punctuation.

Can it play sound?

No, this tool translates to written dots and dashes only.
