About the Stopwatch

A simple, accurate online stopwatch. Press Start to begin timing, Pause to hold the time and Reset to return to zero. It works on phones and computers without any download, so it is handy for workouts, study sessions, cooking and quick experiments.

How to use

  1. Click Start to begin timing.
  2. Click Pause to stop and keep the current time.
  3. Click Reset to set the stopwatch back to zero.

Where it is useful

  • Timing workouts, runs and study sessions.
  • Measuring how long a task takes.
  • Cooking and experiments where seconds matter.
  • Games, quizzes and classroom activities.

Tips for accuracy

The stopwatch uses your device's clock and is accurate enough for everyday timing. Browsers may slow tabs that are in the background, so keep the page open and visible for the most reliable result.

Tips and common mistakes

  • Use Pause to hold the time and Start to continue from it.
  • Press Reset to return to zero before a new measurement.
  • For countdowns use the Countdown Timer instead.
  • Do not rely on a browser stopwatch for sports records or official timing.

Frequently asked questions

Is the stopwatch accurate?

It is accurate enough for everyday use. Browsers may slow timers in background tabs, so keep the page visible for the best results.

Can I resume after pausing?

Yes. Press Start again to continue from the paused time.

Does it work on mobile?

Yes, it works in any modern mobile or desktop browser.

Does it work offline?

Once the page has loaded, yes.

Does it record laps?

Not yet. It measures a single running time.
