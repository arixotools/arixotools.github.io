About the Date Calculator

The Date Calculator tells you how many days lie between a start date and an end date. It is useful for planning projects, counting days to an event, checking notice periods or working out how long something took.

How to use

  1. Enter the start date.
  2. Enter the end date.
  3. Click Calculate to see the number of days.

Where it is useful

  • Counting days between two dates for deadlines.
  • Planning projects and travel.
  • Working out notice periods.
  • Calculating how long something has lasted.

Worked example

From 1 January 2026 to 31 March 2026 there are 89 days. Whether you include both end dates in your own count is up to you; add one if you do.

Tips and common mistakes

  • Decide whether your count includes the start day, the end day or both.
  • Use the Working Days Calculator to skip weekends.
  • Use Add or Subtract Days when you know the number of days and need the date.
  • Check legal deadlines against the exact rule that applies.

Frequently asked questions

Are the start and end dates both counted?

The result is the difference between the two dates. If you need to include both days in your count, add one.

Does it handle leap years?

Yes. Calendar dates are handled by your browser, so leap years are counted correctly.

Can I get the result in months?

This tool shows days. For years, months and days, use the Age Difference Calculator.

Does it include weekends?

Yes, all calendar days are counted.

Can it count months?

It shows days. Use the Age Difference tool for years and months.
