About the Date Calculator

The Date Calculator tells you how many days lie between a start date and an end date. It is useful for planning projects, counting days to an event, checking notice periods or working out how long something took.

How to use

  1. Enter the start date.
  2. Enter the end date.
  3. Click Calculate to see the number of days.

Frequently asked questions

Are the start and end dates both counted?

The result is the difference between the two dates. If you need to include both days in your count, add one.

Does it handle leap years?

Yes. Calendar dates are handled by your browser, so leap years are counted correctly.

Can I get the result in months?

This tool shows days. For years, months and days, use the Age Difference Calculator.
