Number Base Converter

Convert between binary, octal, decimal, hexadecimal and base 36.

About the Number Base Converter

Computers store numbers in binary, programmers read them in hexadecimal, and everyday life uses decimal. This converter changes a number from binary, octal, decimal, hexadecimal or base 36 into all the others at once. It handles very large numbers exactly, so long binary strings and big hex values convert without rounding.

How to use the Number Base Converter

  1. Type the number. A leading 0x or 0b prefix is accepted.
  2. Choose the base the number is written in.
  3. Click Convert.
  4. Read the decimal, binary, octal, hexadecimal and base 36 forms.

Where it is useful

  • Computer science and electronics homework.
  • Reading memory addresses, colour codes and bit flags.
  • Debugging network masks and permissions.
  • Understanding how numbers look in different bases.

How base conversion works

Each digit of a number is multiplied by the base raised to its position. For example, binary 1011 is 1×8 + 0×4 + 1×2 + 1×1 = 11 in decimal. Hexadecimal uses the digits 0 to 9 and A to F, where A is 10 and F is 15.

Tips and common mistakes

  • Letters are not case sensitive. FF and ff are the same.
  • Only whole non-negative numbers are supported.
  • Enter only digits valid for the base. Binary accepts only 0 and 1.
  • One hex digit equals exactly four binary digits, which makes hex a compact way to write binary.

Frequently asked questions

How do I convert binary to decimal?

Multiply each binary digit by a power of 2 and add them up, or paste it here and choose base 2.

What is 255 in hex?

255 is FF in hexadecimal and 11111111 in binary.

What is base 36?

It uses digits 0 to 9 and letters A to Z, giving 36 symbols.

Does it support fractions or negatives?

No. It converts non-negative whole numbers.

How big a number can I convert?

Very large numbers work, because the tool uses exact big-integer arithmetic.
