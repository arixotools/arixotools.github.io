About the Password Generator

The Password Generator creates random passwords that are hard to guess. Choose a length from short to long and decide whether to include uppercase letters, lowercase letters, numbers and symbols. Longer passwords with mixed characters are harder to crack.

How to use

  1. Set the password length with the slider.
  2. Select the character types you want to include.
  3. Click Generate Password, then Copy.

Frequently asked questions

How long should a strong password be?

At least 12 to 16 characters is a good target. Longer is better, especially for email, banking and password-manager accounts.

Should I reuse passwords?

No. Use a different password for every account and store them in a trusted password manager.

Are generated passwords stored?

No. They are created in your browser and are not saved or sent anywhere.
