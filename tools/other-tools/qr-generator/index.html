About the QR Code Generator

The QR Code Generator turns a link, text or other information into a QR code that phones can scan. Enter your content, generate the code and download it as an image. Note that the content you enter is sent to a third-party QR service (api.qrserver.com) to draw the image, so avoid entering sensitive information.

How to use

  1. Enter a link or text in the box.
  2. Click Generate QR.
  3. Click Download to save the QR code image.

Where it is useful

  • Linking posters, menus and cards to a web page.
  • Sharing contact or event details quickly.
  • Creating codes for Wi-Fi and payment links.
  • Adding scannable links to printed material.

Making a QR code that scans well

Keep the content short, because less data gives a simpler, easier-to-scan code. Print it large enough, leave a clear blank border around it, and use dark code on a light background. Always scan it with a phone before printing many copies.

Privacy note: this tool sends the text you enter to a third-party QR service to draw the image, so avoid entering anything sensitive.

Tips and common mistakes

  • Test the code on more than one phone.
  • Use a short link for a cleaner pattern.
  • Do not place logos or colors that reduce contrast.
  • Check that the link still works before printing.

Frequently asked questions

What can I put in a QR code?

Website links, plain text and other short information such as a phone number or Wi-Fi details.

Do QR codes expire?

A QR code that holds a link or text does not expire by itself. If the link goes offline, the code will lead nowhere.

Is the text I enter private?

The text is sent to a third-party QR image service to create the code, so do not enter passwords or other sensitive data.

Does a QR code expire?

A code holding a fixed link or text does not expire, but the page it points to might disappear.

What can I put in it?

Links, plain text, phone numbers and other short information.
